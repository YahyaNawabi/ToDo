# ToDo App
# 📝 Task Manager

A simple and interactive task manager web app built with HTML, CSS, and JavaScript. Users can add tasks along with a specific time, view them in a table, and delete them as needed.

## 🚀 Features
- Add tasks with a specified time
- Display tasks in a clean, auto-numbered table
- Delete individual tasks with one click
- Responsive and user-friendly design
- Uses vanilla JavaScript — no frameworks required

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
